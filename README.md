# Магическое слово

Одностраничный рандомайзер предсказаний. Нажимаешь кнопку — появляется предсказание.
Никаких зависимостей и сборки на стороне GitHub: обычные статические файлы.

## Как работает

- Предсказания лежат в **`a.txt`**, по одному в строке, формат `номер. текст`.
- `build.js` читает `a.txt` и генерирует `predictions.js` — массив, который подключает страница.
- Страница показывает предсказания **без повторов**: колода перемешивается, каждое выдаётся
  один раз, после 50-го — начинается новый круг (появляется плашка «Новый круг предсказаний»).
- Внизу счётчик «Показано N из 50» и полоса прогресса.

## Файлы

| Файл | Назначение |
|------|------------|
| `a.txt` | источник предсказаний (правим руками) |
| `build.js` | `a.txt` → `predictions.js` |
| `predictions.js` | сгенерированные данные (коммитится в репозиторий) |
| `index.html` | разметка + SVG-рисунки сотрудников и запчастей |
| `style.css` | оформление |
| `app.js` | логика: колода, показ, прогресс, декорации |
| `favicon.svg` | иконка вкладки |

## Локальный запуск

Просто открой `index.html` в браузере — всё работает с диска.

Если хочешь локальный сервер (ближе к тому, как будет на GitHub Pages):

```bash
python3 -m http.server 8000
# затем открыть http://localhost:8000
```

## Добавить или изменить предсказания

1. Отредактируй `a.txt` (каждая строка — `номер. текст`).
2. Пересобери данные:

   ```bash
   node build.js
   ```

3. Проверь, что число предсказаний совпадает с ожидаемым, и закоммитай изменения.

Скрипт подскажет, если строка не соответствует формату, если номер повторяется
или если предсказаний не осталось совсем.

## Публикация на GitHub Pages

Репозиторий: <https://github.com/ryabinin13/magic_word>
Адрес сайта после публикации: <https://ryabinin13.github.io/magic_word/>

В репозитории уже лежит всё нужное, включая `predictions.js`, поэтому Pages
ничего собирать не будет — просто отдаёт файлы как есть.

Код в этой папке уже закоммичен, осталось отправить его на GitHub. Нужен любой
из двух вариантов.

**Вариант 1 — SSH-ключ** (если ключа ещё нет):

```bash
ssh-keygen -t ed25519 -C "ryabinin13@users.noreply.github.com"
cat ~/.ssh/id_ed25519.pub
```

Скопированный вывод вставить в GitHub: **Settings → SSH and GPG keys → New SSH key**.
Потом:

```bash
cd ~/code/magic_word
git remote set-url origin git@github.com:ryabinin13/magic_word.git
git push -u origin main
```

**Вариант 2 — токен** (если ключ настраивать не хочется):

Создай токен: **GitHub → Settings → Developer settings → Personal access tokens →
Fine-grained tokens → Generate**, доступ только к репозиторию `magic_word`,
разрешение **Contents: Read and write**. Дальше:

```bash
cd ~/code/magic_word
git push -u origin main
# в поле Username: ryabinin13
# в поле Password: вставь токен
```

После отправки включи сам сайт в репозитории:

**Settings → Pages → Build and deployment → Source: Deploy from a branch**,
ветка `main`, папка `/ (root)`. Через минуту-полторы сайт будет доступен по адресу:

```
https://ryabinin13.github.io/magic_word/
```

Дальше каждое обновление предсказаний — это `node build.js`, `git add .`, `git commit`, `git push`.

## Мелочи

- Работает без JavaScript? Нет — без него покажется просьба его включить.
- Уважает системную настройку «уменьшить движение»: анимации и ходячие человечки отключаются.
- Шрифт рукописный (Comic Neue) подгружается с Google Fonts; без интернета отработает запасной.
