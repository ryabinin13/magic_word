# Магическое слово

Одностраничный рандомайзер предсказаний. Нажимаешь кнопку — появляется предсказание.
Никаких зависимостей и сборки на стороне GitHub: обычные статические файлы.

## Как работает

- Предсказания лежат в **`new.txt`**, по одному в строке, формат `номер. текст`.
- `build.js` читает `new.txt` и генерирует `predictions.js` — массив, который подключает страница.
- Страница показывает предсказания **без повторов**: колода перемешивается, каждое выдаётся
  один раз, после 50-го — начинается новый круг (появляется плашка «Новый круг предсказаний»).
- На странице живёт макет из Photoshop (картинка `assets/design.png`) и поверх него —
  номер, текст предсказания и кнопка. Шрифт системный, никаких внешних шрифтов и запросов.

## Файлы

| Файл | Назначение |
|------|------------|
| `new.txt` | источник предсказаний (правим руками) |
| `build.js` | `new.txt` → `predictions.js` |
| `predictions.js` | сгенерированные данные (коммитится в репозиторий) |
| `index.html` | разметка страницы |
| `style.css` | оформление |
| `app.js` | логика: колода и показ предсказания |
| `assets/design.png` | макет 1890×1418, который рисуется фоном |
| `new/` | исходник макета: экспорт из Photoshop (срезы + `предсказания.html`) |
| `favicon.svg` | иконка вкладки |

## Как устроен макет

`assets/design.png` — один растровый макет 1890×1418, собран из срезов экспорта
Photoshop (папка `new/`). В макете по центру есть светлая панель **716×243** при
(587, 461) — это готовое место под контент. Внутри неё отступ 34/27 пикселей и
**текстовое поле 648×189** при (621, 488); в него встаёт `#text`, и текст лежит
строго внутри (кегль подгоняется в `fitText()` в `app.js`, если не влезает).

Ещё в этом месте макета:

- `#num` — над панелью (низ подписи на 58 пикселей выше поля);
- `#draw` и `#toast` — под панелью (верх на 53 пикселя ниже поля).

Всё задано в процентах от макета и в `cqw` (1cqw = 18.9 макетных пикселей), поэтому
элементы едут вместе с картинкой.

- **Широкий и высокий экран** (≥ 960×720): макет целиком вписывается в окно
  (`min(100vw, 100svh × 1890/1418)`), контент лежит на панели макета.
- **Телефон, портретный планшет, низкое окно** (< 960×720): макет занимает всю
  высоту экрана и срезается по бокам — панель с текстом остаётся на месте,
  контент не уезжает с картинки, страница не скроллится ни в одну сторону.

Чтобы заменить дизайн: положи новую картинку в `assets/design.png` (желательно те же
1890×1418), а если панель сдвинулась — поправь проценты `.card`, `top`/`bottom` у
`.num` и `.actions`. Контраст замеряется по скриншоту: тёмно-синий `#001c4f` на
светлой панели даёт ≈ 10:1, на золоте ≈ 8:1.


## Локальный запуск

Просто открой `index.html` в браузере — всё работает с диска.

Если хочешь локальный сервер (ближе к тому, как будет на GitHub Pages):

```bash
python3 -m http.server 8000
# затем открыть http://localhost:8000
```

## Добавить или изменить предсказания

1. Отредактируй `new.txt` (каждая строка — `номер. текст`).
2. Пересобери данные:

   ```bash
   node build.js
   ```

3. Проверь, что число предсказаний совпадает с ожидаемым, и закоммитай изменения.

Скрипт подскажет, если строка не соответствует формату, если номер повторяется
или если предсказаний не осталось совсем.

## Публикация на GitHub Pages

Репозиторий: <https://github.com/ryabinin13/magic_word>
Адрес сайта после публикации: <https://ryabinin13.github.io/magic_word/>

В репозитории уже лежит всё нужное, включая `predictions.js`, поэтому Pages
ничего собирать не будет — просто отдаёт файлы как есть.

Код в этой папке уже закоммичен, осталось отправить его на GitHub. Нужен любой
из двух вариантов.

**Вариант 1 — SSH-ключ** (если ключа ещё нет):

```bash
ssh-keygen -t ed25519 -C "ryabinin13@users.noreply.github.com"
cat ~/.ssh/id_ed25519.pub
```

Скопированный вывод вставить в GitHub: **Settings → SSH and GPG keys → New SSH key**.
Потом:

```bash
cd ~/code/magic_word
git remote set-url origin git@github.com:ryabinin13/magic_word.git
git push -u origin main
```

**Вариант 2 — токен** (если ключ настраивать не хочется):

Создай токен: **GitHub → Settings → Developer settings → Personal access tokens →
Fine-grained tokens → Generate**, доступ только к репозиторию `magic_word`,
разрешение **Contents: Read and write**. Дальше:

```bash
cd ~/code/magic_word
git push -u origin main
# в поле Username: ryabinin13
# в поле Password: вставь токен
```

После отправки включи сам сайт в репозитории:

**Settings → Pages → Build and deployment → Source: Deploy from a branch**,
ветка `main`, папка `/ (root)`. Через минуту-полторы сайт будет доступен по адресу:

```
https://ryabinin13.github.io/magic_word/
```

Дальше каждое обновление предсказаний — это `node build.js`, `git add .`, `git commit`, `git push`.

## Мелочи

- Работает без JavaScript? Нет — без него покажется просьба его включить.
- Уважает системную настройку «уменьшить движение»: переходы отключаются.
- Шрифт системный, внешних запросов нет — страница работает без интернета.
